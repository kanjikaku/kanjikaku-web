KanjiKaku 애플리케이션 개인정보 처리방침

최종 수정일: 2026년 9월 24일

요약: 학습 데이터는 사용자의 기기 외부로 전송되지 않습니다. 본 애플리케이션은 계정 생성을 요구하지 않으며, 개발자가 운영하는 어떠한 서버에도 데이터를 저장하지 않고, 광고를 표시하거나 분석 도구를 실행하지 않습니다.

다음 항목들은 저장되는 데이터의 종류와 저장 위치, 본 애플리케이션이 네트워크 연결을 생성하는 모든 경우를 상세히 규정합니다.

저장되는 데이터 및 저장 위치

조회한 한자, 각 한자별 숙련도 기록, 덱 및 묶음, 애플리케이션 설정, 세션 기록을 포함한 모든 학습 데이터는 사용자 기기 내 애플리케이션 전용 파일에 저장됩니다.

해당 데이터는 기기 내에만 보관됩니다. 어떠한 서버로도 복사되지 않으며 개발자나 제3자가 접근할 수 없습니다. 애플리케이션 삭제 시 해당 데이터도 함께 삭제됩니다.

본 애플리케이션은 필기 연습과 관련하여 실패한 시도에서 입력된 획 정보 및 각 시도에 대한 수치 데이터를 로컬 기기에 기록합니다. 이 기록은 최대 100자 및 500회 시도까지 보관되며 초과 시 가장 오래된 기록부터 순차적으로 파기됩니다. 해당 기록의 유일한 목적은 사용자가 자발적으로 개발자에게 오류 내역을 전송할 수 있도록 하는 것이며, 자동으로 전송되지 않고 '설정' 메뉴에서 언제든지 삭제할 수 있습니다.

본 애플리케이션이 수행하지 않는 행위

  • 계정 생성이나 회원가입을 요구하지 않습니다. 성명, 이메일 주소, 연령 등의 정보를 일절 요구하지 않습니다.
  • 개발자는 사용자의 학습 진행 상황을 저장하는 서버를 운영하지 않습니다.
  • 광고를 표시하지 않으며 광고 네트워크를 연동하지 않습니다.
  • 데이터 분석이나 사용 현황 추적을 수행하지 않으며 광고 식별자를 사용하지 않습니다. 오류 보고 기능이 존재하나 사용자가 직접 활성화하지 않는 한 비활성화 상태로 유지되며, 이에 대한 상세 내용은 아래 별도 항목에 기술되어 있습니다.
  • 해당 목적을 위한 데이터를 수집하지 않으므로 어떠한 데이터도 제3자에게 판매하거나 공유하지 않습니다.

네트워크 연결

본 애플리케이션은 아래에 명시된 경우에 한하여 네트워크에 연결됩니다. 어떤 경우에도 학습 데이터는 전송되지 않습니다.

1 · 업데이트. 애플리케이션 실행 시, 최신 버전이 있는지 확인하기 위해 Expo Application Services(미국 Expo사)의 업데이트 서비스를 조회합니다. 해당 요청을 통해 기기의 IP 주소, 운영체제, 애플리케이션 버전 등의 기술적 데이터가 해당 서비스에 전달될 수 있습니다. 학습 데이터는 전송되지 않습니다. Expo의 개인정보 처리방침은 expo.dev/privacy에서 확인하실 수 있습니다.

2 · 음성 합성. 애플리케이션이 일본어 단어를 소리 내어 읽을 때는 기기 자체의 텍스트 음성 변환(TTS) 엔진을 사용합니다. 애플리케이션 자체는 어떠한 데이터도 전송하지 않으며, 해당 시스템 엔진의 네트워크 사용 여부는 기기 및 기기 설정에 따릅니다.

3 · 오류 보고서(동의 기반). 하단의 해당 항목에 상세히 설명되어 있습니다. 사용자가 직접 활성화하지 않는 한 비활성화 상태로 유지됩니다.

사본 내보내기 및 가져오기

사용자는 언제든지 학습 데이터 사본을 내보낼 수 있습니다. 애플리케이션은 파일을 생성하여 운영체제의 공유 대화상자로 전달할 뿐이며, 이후의 저장 위치는 전적으로 사용자가 결정합니다. 그 시점부터 해당 파일은 전송된 대상 서비스의 이용약관 및 정책을 따릅니다. 애플리케이션은 해당 파일을 어떠한 외부 서버에도 업로드하지 않습니다.

가져오기는 역순으로 동작합니다. 사용자가 파일을 선택하면 애플리케이션이 이를 읽어 현재의 학습 데이터를 해당 파일의 내용으로 교체합니다. 사용자가 명시적으로 선택한 파일에 한해서만 접근합니다.

알림

일일 알림을 활성화하면 기기 자체에 예약됩니다. 별도의 알림 서버나 푸시 토큰은 존재하지 않습니다. 애플리케이션은 알림 확인 여부를 파악할 수 없으며, 기기 외부에서 생성되는 알림 또한 일절 없습니다.

권한

  • 알림 — 일일 알림을 활성화한 경우에만 요청합니다.
  • 파일 — 내보내기 또는 가져오기를 실행하는 시점에만 요청하며, 선택한 파일로 제한됩니다.
  • 마이크 — 소리 내어 읽기 기능을 제공하는 학습에서만 요청되며, 해당 버튼을 누르고 있는 동안에만 활성화됩니다. 음성 인식은 기기 내에서 처리됩니다(하단 항목 참조).
  • 본 애플리케이션은 카메라, 위치 정보, 연락처 및 사진에 접근하지 않습니다.

소리 내어 읽기와 마이크

일부 학습에서는 단어를 직접 입력하는 대신 소리 내어 읽을 수 있습니다. 마이크는 권한이 허용된 경우에 한하여, 해당 버튼을 누르고 있는 동안에만 활성화됩니다.

음성 인식은 기기 내에서 처리됩니다. 본 애플리케이션은 기기 자체의 음성 인식기에 온디바이스 인식을 요청하며, 다른 수단은 일절 사용하지 않습니다. 기기에서 네트워크 연결 없이 일본어를 인식할 수 없는 경우 해당 기능은 제공되지 않습니다.

오디오는 일절 녹음되거나 보관되지 않습니다. 애플리케이션은 인식된 텍스트만 전달받아 정답 읽기와 대조한 뒤 즉시 폐기합니다. 어떠한 오디오 파일도 생성되지 않으며, 외부로 전송되지 않습니다.

오류 보고서

오류 수정을 위해, 애플리케이션이 예기치 않게 종료되는 경우 보고서를 전송할 수 있습니다. 이 기능은 기본적으로 비활성화되어 있습니다. 앱 최초 실행 시 동의를 요청하며, 동의하기 전까지는 어떠한 정보도 전송되지 않습니다.

활성화된 경우 보고서는 해당 수집 서비스인 Sentry(미국 Functional Software, Inc.)로 전송됩니다. 보고서에는 코드 내 결함의 성격과 위치, 애플리케이션 버전 및 기기 모델명이 포함됩니다.

학습 데이터, 덱, 애플리케이션 설정 또는 사용자를 식별할 수 있는 정보는 일절 포함되지 않습니다. 개인정보가 첨부될 수 있는 옵션은 코드상에서 비활성화되어 있습니다. 보고서 전송 기능은 설정에서 언제든지 다시 비활성화할 수 있습니다.

Sentry의 개인정보 처리방침은 sentry.io/privacy에서 확인하실 수 있습니다.

미성년자

본 애플리케이션은 연령과 무관하게 사용자의 어떠한 개인정보도 수집하지 않습니다. 이름, 이메일 주소, 생년월일을 요구하지 않으므로, 별도로 보관하거나 처리해야 할 미성년자 관련 데이터 자체를 보유하지 않습니다.

이메일 지원

사용자가 문제를 신고하기 위해 문의하거나 ‘설정’에서 필기 기록을 전송하는 경우, 개발자는 전송된 내용과 발신 이메일 주소를 수신합니다.

  • 수집되는 데이터. 이메일 주소, 메시지 및 첨부 파일(포함된 경우). 해당 파일에는 획, 수치, 애플리케이션 버전 및 애플리케이션 설정 정보가 포함되며, 사용자를 식별할 수 있는 어떠한 정보도 포함되지 않습니다.
  • 목적. 접수된 문제를 검토하고 답변하며, 애플리케이션이 필기를 의도보다 어렵게 처리하는 부분을 파악하기 위함입니다.
  • 법적 근거. 메시지 전송을 통해 부여된 사용자의 동의. 해당 행위가 없으면 어떠한 처리도 이루어지지 않습니다.
  • 보유 기간. 사안이 해결될 때까지 보관하며, 어떠한 경우에도 6개월을 초과하지 않습니다.

사용자는 하단에 기재된 주소를 통해 언제든지 이메일 주소 및 전송된 모든 자료의 삭제를 요청할 수 있습니다. 애플리케이션 자체는 앞으로도 어떠한 데이터도 독자적으로 전송하지 않습니다.

정보주체의 권리

열람, 정정 및 삭제에 관한 권리는 통상적으로 상대방이 데이터를 보유하고 있음을 전제로 합니다. 본 애플리케이션은 이에 해당하지 않습니다. 데이터는 사용자의 기기에만 존재하며 사용자의 통제하에 있습니다. 데이터는 사본을 내보내어 확인하거나, 애플리케이션 설정에서 삭제하거나, 애플리케이션을 기기에서 제거하여 삭제할 수 있습니다.

본 방침의 변경

위 사항에 변경이 있을 경우 본 페이지가 수정되며 상단에 표시된 날짜가 그에 맞추어 갱신됩니다. 별도의 공지용 메일링 리스트는 운영되지 않으며, 해당 날짜가 확인의 수단이 됩니다.

언어별 버전

본 정책은 여러 언어로 게시됩니다. 각 버전 간에 차이가 있는 경우 영어 버전이 우선합니다.
