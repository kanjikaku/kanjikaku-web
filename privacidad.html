Privacy policy

Privacy policy for the KanjiKaku application

Last updated: 24 September 2026

In summary: study data does not leave the user's device. The application requires no account, stores nothing on any server operated by the developer, displays no advertising and performs no analytics.

The sections below set out what is stored, where it is stored, and every occasion on which the application establishes a network connection.

Data stored, and where

All study data — the kanji consulted, the level of mastery recorded for each one, decks and batches, application settings and session history — is written to a file within the application itself, on the user's device.

That data remains there. It is not copied to any server and is not accessible to the developer or to any third party. Uninstalling the application deletes it.

The application additionally maintains a local record of handwriting practice: the strokes drawn in unsuccessful attempts and a line of figures for each attempt. The record is capped at 100 characters and 500 attempts, and the oldest entries are discarded. Its sole purpose is to allow the user to send it to the developer voluntarily; it is never transmitted automatically and may be deleted from Settings.

What the application does not do

  • It requires no account and no registration. It does not request a name, an email address or an age.
  • The developer operates no server holding user progress.
  • It displays no advertising and integrates no advertising networks.
  • It performs no analytics, no usage tracking and uses no advertising identifiers. Crash reporting does exist; it is disabled unless the user enables it, and is described in a separate section below.
  • No data is sold or shared with third parties, as no data is collected for that purpose.

Network connections

The application establishes a network connection on the occasions listed below. None of them transmits study data.

1 · Updates. On launch, the application queries the update service of Expo Application Services (Expo, United States) to determine whether a more recent version exists. That request allows the service to observe technical data: the device IP address, its operating system and the application version. It transmits no study data. Expo's privacy policy is available at expo.dev/privacy.

2 · Speech synthesis. When the application reads a Japanese word aloud, it delegates to the text-to-speech engine of the device itself. The application transmits nothing on its own account; whether that system engine uses the network depends on the device and its configuration.

3 · Crash reports, subject to consent. Described in the corresponding section below. Disabled unless the user enables them.

Exporting and importing a copy

The user may export a copy of the study data at any time. The application writes a file and delivers it to the operating system share dialog; its subsequent destination is determined solely by the user, and from that point the file is governed by the terms of the service to which it is sent. The application does not upload it anywhere.

Importing operates in reverse: the user selects a file, and the application reads it and replaces the current study data with its contents. Only the file expressly selected is read.

Reminders

If the daily reminder is enabled, it is scheduled on the device itself. There is no notification server and no push token: the application cannot determine whether a reminder was seen, and no notification originates from outside the device.

Permissions

  • Notifications — requested only if the daily reminder is enabled.
  • Files — requested only at the moment of exporting or importing, and limited to the file selected.
  • Microphone — requested only for the exercises that offer reading aloud, and active only while the corresponding button is held. Recognition is performed on the device; see the section below.
  • The application does not access the camera, location data, contacts or photographs.

Reading aloud and the microphone

Certain exercises allow the word to be read aloud instead of typed. The microphone is opened only while the corresponding button is held, and only after the permission has been granted.

Recognition is performed on the device. The application requests on-device recognition from the device speech recogniser and uses no other means: where the device cannot recognise Japanese without a network connection, the function is not offered.

No audio is recorded and no audio is retained. The application receives the recognised text, compares it with the expected reading and discards it. No audio file is written, and no audio leaves the application.

Crash reports

The application is able to transmit a report when it terminates unexpectedly, so that the defect can be corrected. This function is disabled by default. Consent is requested on first launch, and nothing is transmitted until it is granted.

Where enabled, the report is transmitted to Sentry (Functional Software, Inc., United States), the service that collects such reports. It contains the nature and location of the defect within the code, the application version and the device model.

It does not contain study data, decks, application settings or any information identifying the user: the option that would attach personal data is disabled in the code. Reports may be disabled again from Settings at any time.

Sentry's privacy policy is available at sentry.io/privacy.

Minors

The application collects no personal data from any user, irrespective of age. It does not request a name, an email address or a date of birth, and therefore holds no data relating to a minor that could be stored or processed differently.

Support by email

Where the user writes to report a problem, or sends the handwriting record from Settings, the developer receives the content sent and the email address from which it was sent.

  • Data received. The email address, the message, and the attached file where one is included. The file contains strokes, figures, the application version and the application settings; it contains nothing identifying the user.
  • Purpose. To assess the issue reported, to reply, and to determine where the application makes handwriting more difficult than intended.
  • Legal basis. The consent of the user, given by sending the message. No processing occurs in the absence of that act.
  • Retention period. Until the matter is resolved, and in no case longer than six months.

The user may request deletion of the email address and of any material sent, at any time, at the address given below. The application itself continues to transmit nothing on its own account.

Rights of the data subject

The rights of access, rectification and erasure ordinarily presuppose that a party holds the data. That is not the case here: the data resides on the user's device and under the user's control. It may be inspected by exporting a copy and deleted from the application settings or by uninstalling the application.

Amendments to this policy

Where any of the above changes, this page is amended and the date shown above is updated accordingly. There is no mailing list through which notice is given; the date is the means of verification.

Language versions

This policy is published in several languages. In the event of any discrepancy between the versions, the English version shall prevail.
